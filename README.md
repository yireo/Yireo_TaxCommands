> This Magento 2 module adds various CLI commands to handle tax rates, tax rules and more

### Installation
Install this package via composer:
```bash
composer require yireo/magento2-tax-commands
```

Next, enable this module:
```bash
bin/magento module:enable Yireo_TaxCommands
```
